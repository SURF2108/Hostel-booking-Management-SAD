# Autonomous execution runbook
1. Inspect workspace, git status, diagrams and available Node/npm/MongoDB/browser tools. Preserve user changes. Write source audit, traceability, role matrix, data model and concise plan. Proceed immediately without waiting for routine plan approval when the host allows it.
2. Scaffold root workspace and client/server, lock dependencies, configure env and ignore rules. Establish database connection and test strategy. Prefer existing valid configs; do not overwrite originals indiscriminately.
3. Implement backend in vertical slices: auth and role checks, inventory/availability, booking lifecycle, remaining confirmed use cases. Write tests alongside each slice. Verify race protection and invariants before UI integration.
4. Implement shared UI system and role-specific pages. Connect all actions to real APIs, including loading and error states. Implement accessible responsive layouts. No placeholder routes.
5. Seed fictional demo records for every confirmed role and useful lifecycle state. Provide local-only demo login instructions, guarded seed behavior and reset guidance that never targets production.
6. Run install, lint, unit/integration tests, build, seed, startup and browser end-to-end checks. Fix root causes instead of disabling checks. Inspect browser console and network. Iterate through quality gate. Use isolated test data. Only run commands with necessary permission; never bypass host approvals.
7. Update README with exact Windows-compatible commands, prerequisites, ports, environment variables, demo accounts, troubleshooting and architecture. Generate docs/API.md, docs/TRACEABILITY.md, docs/TEST_REPORT.md and docs/BUILD_STATUS.md. Preserve diagrams. Save key screenshots under docs/screenshots if tools permit. Report actual results, not estimates.
Keep progress checklist in docs/BUILD_STATUS.md: phase, completed files, commands, exit codes, remaining work, blockers and next command. If context or credits run out, resume from that file using master prompt; avoid regenerating completed work. Prefer a single agent and batched related tasks to save credits. Do not repeatedly browse or reinstall without reason. Never stop at plan or scaffold unless blocked by permissions/resources. Do not commit/push/deploy unless explicitly requested.
