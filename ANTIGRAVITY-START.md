# Setup instructions
1. Install Git, a maintained Node.js LTS release (npm included), and a local MongoDB installation or Docker Desktop if using the optional replica-set configuration. Alternatively have a MongoDB URI ready. Open the repository root in Antigravity, not the diagrams folder.
2. Extract this ZIP directly into the cloned repository root. Keep original README.md and diagrams/ unchanged. If AGENTS.md already exists, merge it instead of replacing user instructions. The .agents directory must be present.
3. Open antigravity-setup/MASTER_PROMPT.md, copy its complete text into a new Antigravity agent conversation and submit. Allow the agent to edit project files and run appropriate local development commands; retain approvals for sensitive actions. No need to send separate frontend/backend prompts.
4. If interrupted, use the resume prompt: Read AGENTS.md, all setup guides and docs/BUILD_STATUS.md. Inspect git diff and existing files. Resume from the first unfinished phase. Do not regenerate working code. Run remaining quality checks and report actual outcomes.
This ZIP is an agent setup, not a finished MERN application. Repository root structure was verified; diagram contents could not be retrieved remotely, so local source audit is mandatory. Suggested features are provisional. Current Antigravity rules docs: https://antigravity.google/docs/rules/ .
